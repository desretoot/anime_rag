# Anime RAG Bot (GigaChat Edition)

Telegram-бот с системой рекомендаций аниме на основе RAG (Retrieval-Augmented Generation) и GigaChat API.

## 🚀 Возможности

- Рекомендации аниме по жанрам и предпочтениям
- Интеллектуальные ответы с помощью GigaChat
- Поиск по базе данных аниме с Shikimori
- Интеграция с Telegram
